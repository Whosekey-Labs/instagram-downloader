# Open Media Downloader

**Instagram 계정의 사진·동영상·릴스를 선택해서 내 컴퓨터에 저장하는 무료 오픈소스 Chrome 확장입니다.**

초기 테스트 버전(0.1.0)입니다. 실제 Instagram에서의 파일 저장과 Chrome 웹스토어 심사는 아직 완료되지 않았습니다. 진행 상태는 [검증 기록](docs/verification.md)을 확인하세요.

## 로컬 설치

1. [Releases](https://github.com/Whosekey-Labs/instagram-downloader/releases)에서 ZIP을 내려받고 폴더에 압축을 풉니다. 소스에서 빌드한다면 Node.js 22 이상에서 `npm run build`를 실행합니다. 의존성 설치는 필요하지 않습니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다. 소스 빌드는 `dist/`를 선택하세요. ZIP 자체를 선택하지 않습니다.
5. 확장 아이콘을 눌러 작업 화면을 엽니다. 이미 열려 있던 Instagram 탭은 새로고침합니다.

로컬 설치에는 스토어 심사가 필요하지 않습니다. 일반 배포를 위한 웹스토어 등록에는 별도 개발자 등록과 심사가 필요합니다.

## 사용

1. 계정명(`meta`)이나 프로필 URL을 입력하고 **미디어 불러오기**를 누릅니다.
2. 필요하면 **Instagram 열기**에서 직접 로그인한 뒤 다시 조회합니다. 확장에 비밀번호를 입력하지 않습니다.
3. **12개 게시물 더 가져오기** 또는 **지정 수까지 가져오기**로 목록을 확장합니다. 기본 수집 목표는 48개 게시물이며 12~5000 사이에서 설정할 수 있습니다. 유료 이용 제한은 없습니다. Instagram이 더 적은 결과를 제공할 수 있습니다.
4. 사진/동영상 필터로 목록을 좁히고 필요한 파일을 선택합니다. 묶음 게시물은 파일별로 표시됩니다.
5. **선택한 파일 다운로드**를 누릅니다. 다운로드 폴더의 `OpenMedia/계정명/` 아래에 저장됩니다.

예: `OpenMedia/meta/meta_게시물코드_01.jpg`

기존 파일을 덮어쓰지 않습니다. 동일 파일명은 Chrome이 구분하고, 이 확장에서 성공한 파일은 저장 기록으로 건너뜁니다. 직접 파일을 삭제했거나 재다운로드하려면 화면 하단에서 저장 기록을 지우세요. 작업 탭을 닫으면 조회 목록과 예약 작업이 사라지며 이미 시작된 다운로드는 Chrome에서 계속될 수 있습니다. 작업 중단 버튼은 진행 중 파일도 취소합니다.

## 범위와 한계

- 일반 게시물 사진, 영상, 릴스, 혼합 캐러셀을 지원합니다. Stories/Highlights는 아직 지원하지 않습니다.
- Instagram이 현재 세션에 제공하는 콘텐츠만 접근합니다. 비공개 계정 권한이나 로그인 제한을 우회하지 않습니다.
- 공식 Meta Graph API가 아닌 Instagram 웹 응답을 사용합니다. Instagram 변경으로 조회가 중단될 수 있으며 계정 전체 수집이나 차단 없는 동작을 보장하지 않습니다.
- 로그인·인증·429 요청 제한이 나오면 자동 재시도하지 않습니다. Instagram에서 상태를 확인한 뒤 나중에 직접 다시 시도하세요.
- 영상 URL이 없을 때 사진 썸네일을 대신 영상으로 저장하지 않습니다. 제공된 후보 중 가장 큰 해상도를 사용하며 게시자가 업로드한 원본과 동일하다고 보장하지 않습니다.
- 본인 콘텐츠 또는 저장 허락을 받은 콘텐츠에 사용하세요. 콘텐츠의 소유권과 이용 조건은 게시자 및 해당 서비스에 있습니다.
- Chrome 호환 확장 API를 사용하는 Manifest V3 프로그램입니다. 다른 Chromium 브라우저 및 앱 내 브라우저는 확장 API 지원 범위에 따라 달라지며 별도 호환성 검증이 필요합니다.

## 개인정보 및 권한

서버·광고·추적·원격 코드·외부 런타임 라이브러리가 없습니다. 로그인은 Instagram에서 처리하고 완료 식별자와 시각만 Chrome 로컬 저장소에 저장합니다. [개인정보처리방침](PRIVACY.md)을 확인하세요.

| 권한 | 용도 |
| --- | --- |
| downloads | 선택한 파일의 저장과 해당 다운로드 상태 확인 |
| storage | 로컬 완료 기록으로 중복 저장 방지 |
| www.instagram.com | 사용자 요청에 따른 프로필 및 미디어 조회 |

## 개발

```sh
npm test          # 파서·오류·권한 경계·저장 완료/취소 검증
npm run build    # 설치할 dist 폴더 생성
npm run check    # manifest 및 배포 파일 검사
npm run package  # 테스트/빌드/검사 및 ZIP/SHA-256 생성
npm run preview  # http://127.0.0.1:4173 개발용 화면 테스트
```

`preview`는 예시 데이터 및 Chrome API 대역을 사용하는 화면 테스트입니다. 실제 Instagram 요청과 파일 저장을 하지 않으며 노란색 안내가 표시됩니다. 개발용 대역과 예시 자료는 출시 ZIP에 포함되지 않습니다.

```text
src/app.*          작업 화면과 상태 관리
src/content.js     Instagram 동일 출처 요청과 메시지 검증
src/background.js  확장 아이콘 → 작업 탭
src/lib/core.js    입력·CDN 검증 및 미디어 정규화
src/lib/download.js Chrome 실제 다운로드 상태 확인
src/lib/queue.js   순차 저장·중복·취소
scripts/          빌드·검사·패키징·개발 미리보기
tests/            Node 내장 테스트
store/            스토어 문안 및 제출용 이미지
```

## 기여 및 배포

오류 보고 시 브라우저 버전, 확장 버전, 화면의 오류 문구와 재현 단계를 포함하세요. 비밀번호, 쿠키, 인증 코드, 미디어 서명 URL 또는 비공개 콘텐츠를 이슈에 올리지 마세요. 수정 전후 `npm run package`를 실행하세요.

배포 절차와 현재 사용자 전용 단계는 [스토어 제출 안내](store/submission.md), 참고한 오픈소스와 선택 근거는 [조사 기록](docs/research.md)에 있습니다.
