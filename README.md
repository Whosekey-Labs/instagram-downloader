# Open Media Downloader

**Instagram 프로필 안에서 현재 화면의 미디어를 저장하거나, 전체 게시물을 스크롤해 모은 뒤 다운로드하는 무료 오픈소스 확장입니다.**

별도 웹사이트나 작업 탭으로 이동하지 않습니다. 로컬 서버도 필요하지 않습니다. Instagram 페이지 오른쪽 위의 작은 **미디어 저장** 버튼에서 사용합니다.

0.2.0은 사용자가 실제 사용 후 정상 동작을 확인했습니다. 0.3.0에서는 개수 지정 및 기본값 저장을 추가했고 자동 테스트와 예시 프로필 UI를 검증했습니다. 새 기능의 실서비스 검증과 웹스토어 심사는 별도입니다. [검증 기록](docs/verification.md)

## 설치

1. [v0.3.3 ZIP](https://github.com/Whosekey-Labs/instagram-downloader/releases/tag/v0.3.3)을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**로 `manifest.json`이 있는 폴더를 선택합니다.
4. Instagram 탭을 새로고침하고 원하는 계정의 **게시물 탭**으로 이동합니다.

기존 버전을 로드한 경우 같은 `dist/` 폴더로 업데이트하고 확장 관리 화면의 새로고침 버튼 및 Instagram 페이지 새로고침을 모두 수행하세요. 기존 별도 작업 화면은 더 이상 사용하지 않습니다.

## 사용 흐름

1. 브라우저에서 Instagram에 접속하고 원하는 계정 프로필로 이동합니다.
2. 오른쪽 위 **미디어 저장 · N개 게시물** 안내를 누릅니다. 자동으로 창을 열거나 다운로드하지 않습니다.
3. **현재 화면 다운로드**를 누르면 클릭 시점에 화면에 보이는 게시물만 저장합니다. 자동 스크롤하지 않습니다. 여러 장이 묶인 게시물은 그 안의 사진·동영상을 함께 저장합니다.
4. 전체가 필요하면 **전체 다운로드 옵션 → 전체 모은 뒤 다운로드**를 선택합니다. 페이지 위쪽부터 스크롤하며 게시물 주소를 모은 후, 전체 개수가 확인되면 순차 저장합니다.
5. 필요하면 **작업 중단**을 누릅니다. 안내는 접거나 닫을 수 있고, 확장 아이콘으로 다시 열 수 있습니다.

파일은 다운로드 폴더의 `OpenMedia/계정명/` 아래에 저장됩니다. 기존 파일을 덮어쓰지 않고, 이 확장에서 성공한 기록이 있는 항목은 건너뜁니다. 파일을 삭제했거나 다시 저장하려면 전체 옵션 아래의 **이 계정의 저장 기록 지우기**를 사용하세요.

## 개수 지정과 기본값 저장

- **다운로드할 게시물 수**에 1~5000개를 입력하고 **N개 게시물 다운로드**를 누릅니다. 처음 표시되는 값은 20개입니다.
- **기본값 저장**을 누르면 다른 계정으로 이동하거나 브라우저를 다시 열어도 같은 값이 표시됩니다.
- 숫자만 바꾸고 다운로드하면 이번에만 적용됩니다. 다음 계정에서는 저장한 기본값이 다시 표시됩니다.
- 프로필 앞쪽부터 필요한 만큼만 스크롤하고 지정 개수에 도달하면 저장을 시작합니다. 고정 게시물이 먼저 포함될 수 있으므로 날짜순 최신 N개와는 다릅니다.
- 한 게시물의 사진·영상 묶음은 모두 저장합니다. 게시물 1개에 파일 5개가 있으면 파일 5개가 저장됩니다.
- 계정 전체 게시물이 요청한 개수보다 적으면 확인된 전체만 저장합니다. 로딩이 중단되어 개수를 확인하지 못하면 모인 항목 저장 여부를 선택합니다.
- 완료 기록을 지워도 저장한 기본값은 유지됩니다. 다른 기기와 동기화하지 않습니다.

## 전체 수집이 확인되지 않는 경우

프로필 헤더에 화면으로 표시된 정확한 게시물 수와 모은 수를 비교합니다. 개수를 확인하기 위한 별도 프로필 API는 호출하지 않습니다. 추가 로딩이 멈추거나 전체 개수를 알 수 없는 경우, 자동으로 전체 완료라고 표시하지 않습니다. **모인 N개 게시물만 저장**을 별도로 선택할 수 있습니다. 전체 수집은 최대 1,800회의 스크롤 확인 단계로 제한하며, 한도 도달 시에도 부분 수집으로 표시합니다.

로그인·접근 확인 화면, 401/403/429 또는 챌린지 응답에서는 자동 재시도하지 않습니다. Instagram 웹사이트에서 직접 로그인/확인한 뒤 다시 실행하세요. 확장에 비밀번호를 입력하지 않습니다.

## 지원 범위

- 프로필 **게시물 탭**에 표시된 사진·영상·릴스 및 혼합 캐러셀. 프로필 그리드에 공유되지 않은 릴스, Stories, Highlights, Tagged, Reposts는 지원하지 않습니다.
- 화면 가장자리에 조금만 걸친 다음 행과 아바타는 기본 다운로드 대상에서 제외합니다.
- 현재 세션에서 접근 가능한 미디어만 처리합니다. 비공개 계정 권한이나 로그인 제한을 우회하지 않습니다.
- 비공식 Instagram 웹 응답을 사용하므로 사이트 변경으로 중단될 수 있습니다. 계정 전체 수집 또는 차단 없는 동작을 보장하지 않습니다.
- 제공된 후보 중 큰 해상도를 선택합니다. 업로드 원본과 동일하다고 보장하지 않으며, 영상 URL이 없는 경우 썸네일을 영상 대신 저장하지 않습니다.
- 페이지 이동/새로고침/탭 닫기는 이후 예약 작업을 중단합니다. 이미 시작한 다운로드는 Chrome에서 계속될 수 있습니다. **작업 중단** 버튼은 진행 중 파일도 취소합니다.
- 본인 콘텐츠 또는 저장 허락을 받은 콘텐츠에 사용하세요. Instagram / Meta와 무관한 독립 프로젝트입니다.

## 개인정보

서버, 광고, 결제, 추적 및 원격 실행 코드가 없습니다. 완료 식별자·저장 시각은 Chrome 로컬 저장소에, 다운로드의 임시 상태는 브라우저 세션 저장소에 보관합니다. 비밀번호·쿠키 값은 읽거나 저장하지 않습니다. [개인정보처리방침](PRIVACY.md)

권한은 `downloads`, `storage`, `https://www.instagram.com/*`만 사용합니다.

## 개발

Node.js 22.13 이상인 22 버전 또는 Node.js 24 이상이 필요합니다. 개발 도구는 esbuild와 jsdom이며 배포 확장의 런타임에는 외부 라이브러리를 포함하지 않습니다.

```sh
npm ci
npm test
npm run build
npm run check
npm run package
```

`dist/`가 설치할 확장이며, `release/`에 ZIP과 SHA-256이 생성됩니다. `npm run test:ui`는 개발자를 위한 예시 프로필 검증 도구로 실제 Instagram 조회/저장을 하지 않습니다. 사용자용 앱이나 배포 제품이 아닙니다. 테스트 대역은 ZIP에 포함되지 않습니다.

```text
src/content.js              Instagram 페이지 내 확장 진입점
src/inline.js               안내·현재 화면 저장·전체 스크롤·중단 흐름
src/panel-style.js          페이지와 분리된 안내 UI 스타일
src/lib/page.js             화면의 프로필 개수/게시물 링크 읽기
src/lib/post-collection.js  스크롤 수집과 범위 판단
src/lib/post-download.js    모든 모드가 사용하는 공통 다운로드
src/lib/browser-download.js 저장 요청 및 완료 대기
src/lib/instagram.js        해당 게시물의 실제 미디어 조회
src/lib/download-service.js 다운로드 소유권·완료·중복·취소
src/background.js          Chrome 다운로드 API와 도구 모음 연결
```
