# Instagram 페이지 내 다운로드 동선

사용자 확정 요구: Instagram 프로필로 이동한 상태에서 방해가 적은 안내를 표시한다. 기본 버튼은 현재 화면의 미디어만 다운로드한다. 전체 다운로드 옵션은 자동 스크롤로 모두 모은 뒤 저장한다.

- 별도 작업 탭과 localhost 사용자 앱을 제거한다. 작은 접힌 안내 → 현재 화면 다운로드 → 선택적인 전체 옵션으로 구성한다.
- 현재 화면은 클릭 시점의 프로필 게시물 링크와 가시 영역으로 결정한다. 아바타/추천 영역/화면 끝에 걸친 다음 행은 제외하고 공동 게시물 URL은 허용한다.
- 전체 모드는 페이지 상단부터 게시물 링크를 중복 제거하며 모은다. 알려진 프로필 게시물 수에 도달하면 저장 단계로 넘어간다. 로딩 정체/개수 미확인/단계 한도에서는 전체 완료로 오인하지 않고 모인 항목 저장 선택권을 제공한다.
- 하나의 게시물씩 미디어 정보를 조회하고 Chrome 다운로드로 저장한다. 완료 이벤트/조회 결과가 실제 complete인 파일만 기록한다.
- 워커 메모리에 의존하지 않고 임시 상태를 storage.session에 보관한다. 탭·문서·작업 식별자로 상태 조회와 취소 권한을 제한한다.
- 프로필 이동/닫기/취소 시 새 파일 예약을 중단한다. 사용자가 명시한 중단은 현재 파일도 취소한다. Instagram 401/403/429/인증 응답은 자동 재시도하지 않는다.
- 테스트: DOM 가시성, URL/발신자 검증, 수집 완료와 정체, 현재 화면 무스크롤, 닫기/다시 열기/계정 변경, 실제 다운로드 상태와 워커 복원. 예시 UI 검증과 실서비스 파일 저장 증거는 분리한다.
