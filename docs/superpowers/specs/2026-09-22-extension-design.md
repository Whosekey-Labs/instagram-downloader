# Open Media Downloader 설계

사용자 요청: Instagram 계정을 입력해 미디어를 무료로 다운로드하는 오픈소스 크롬 확장을 개발하고, 로컬 테스트 및 웹스토어 심사 요청까지 진행한다.

## 선택한 구조

Manifest V3, 순수 JavaScript, 별도 서버/분석 도구/결제 없음. 확장 아이콘이 독립 작업 탭을 연다. 사용자가 입력한 계정의 Instagram 탭을 열고 해당 탭의 콘텐츠 스크립트에서 동일 출처의 웹 요청을 실행한다. 기존 로그인은 브라우저가 처리하며 비밀번호와 쿠키를 읽거나 보관하지 않는다. 웹 API는 비공식이며 변경될 수 있다.

계정 조회 → 12개 게시물 단위 목록 → 더 가져오기 또는 지정 게시물 수까지 수집 → 사진/동영상 필터 → 선택 다운로드. 기본 수집 상한 48개, 사용자가 12~5000개로 조정. 대량 처리는 순차 실행하며 취소 가능. 더 이상 페이지가 없을 때만 목록 끝으로 표시한다. Stories/Highlights는 이번 초기 버전 범위 밖이다.

미디어 배열에서 제공된 가장 큰 파일을 선택하며 URL 서명을 유지한다. 혼합 캐러셀을 모두 펼친다. 파일명은 계정/게시물/순번으로 결정한다. CDN URL은 HTTPS 및 Instagram CDN 도메인으로 제한한다. 성공한 다운로드의 ID만 로컬 저장하여 중복을 건너뛴다. 개인정보 수집 서버나 외부 메시지는 없다.

## 실패 처리

401/403/429 및 로그인·챌린지 응답에서 자동 재시도하지 않고 중단한다. 응답 형식 변경을 빈 계정으로 오인하지 않는다. 사용자 취소 시 진행 중 파일도 취소하고, 실패는 완료로 기록하지 않는다. 작업 탭을 닫으면 새 요청 예약이 중단되며 Chrome이 이미 시작한 다운로드는 Chrome에서 관리한다.

## 화면

한국어 인터페이스, 밝은 종이색 배경과 짙은 잉크색, 파란색 작업 버튼. 계정 입력과 수집 한도, 미디어 그리드, 선택/중단/완료 수가 보이는 고정 다운로드 바. 외부 폰트 없음. 접근성 레이블과 키보드 포커스 제공.

## 검증 및 출시

입력·URL 검증, 원본 후보 선택, 캐러셀, 오류 분류, 페이지 종료, 중복 기록, 취소 및 다운로드 완료 상태를 자동 테스트한다. 데모 UI 검증과 실서비스 검증은 구분한다. ZIP에는 실행 파일과 라이선스만 포함한다. 공개 MIT 저장소, README, 개인정보처리방침, 스토어 설명/권한 사유/심사 테스트 지침/아이콘/스크린샷을 준비한다. 대시보드 로그인 및 개발자 등록이 완료되면 실제 제출을 진행한다. 로그인·결제·약관 승낙 등 사용자 전용 단계는 상태를 보고한다.
