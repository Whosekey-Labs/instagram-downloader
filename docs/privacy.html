OPEN MEDIA DOWNLOADER

개인정보처리방침

시행일: 2026-09-22 · 버전 0.1.0

처리 목적과 데이터

입력한 계정명, 프로필, 게시물 설명, 미디어 주소와 썸네일을 목록 표시와 파일 저장을 위해 작업 탭의 메모리에서 처리합니다. 탭을 닫으면 목록은 사라집니다. 저장 완료 기록은 계정명·게시물 식별자·순번과 저장 시각으로 구성되며 중복 방지를 위해 Chrome 로컬 저장소에 최대 20,000건 보관합니다. 동기화 저장소는 사용하지 않습니다.

네트워크와 로그인

Instagram 탭에서 Instagram에 직접 조회하며, 미디어는 Instagram/Meta CDN에서 받습니다. 해당 서비스에 IP 주소와 브라우저 요청 정보가 전달됩니다. 로그인은 Instagram에서 직접 진행하며 브라우저가 기존 세션을 처리합니다. 확장은 비밀번호·인증 코드·쿠키 값을 읽거나 저장하지 않습니다.

개발자 수집 서버, 광고, 분석 도구, 추적, 원격 로그 전송이 없습니다. 데이터 판매, 제3자 광고 제공, AI 학습에 사용하지 않습니다. Instagram과 Chrome의 자체 데이터 처리에는 각 서비스 정책이 적용됩니다.

권한

downloads: 선택한 파일 저장 및 상태 확인. storage: 로컬 완료 기록. www.instagram.com 사이트 권한: 사용자가 요청한 프로필과 미디어 조회. 다른 사이트 페이지는 읽지 않습니다.

삭제

'이 확장의 저장 기록 지우기' 또는 확장 제거로 로컬 완료 기록을 삭제할 수 있습니다. 다운로드 파일과 Chrome 다운로드 기록은 별도로 삭제해야 합니다.
