# 검증 기록 · 0.2.0

2026-09-22

## 변경된 실제 제품

별도 작업 탭을 제거했습니다. 설치 패키지에는 `app.html`이 없습니다. Instagram 프로필에 작은 안내를 표시하고 기본 버튼으로 현재 화면만 저장합니다. 전체 옵션에서만 스크롤 수집을 실행합니다. localhost 화면은 제품이 아닙니다.

## 자동 검증

Node 자동 테스트 27개 및 빌드/패키지 검사를 통과했습니다.

- 실제 DOM 기반 가시성/아바타/중복/공동 게시물 링크 선택
- 현재 화면 다운로드에서 스크롤 및 전체 계정 조회가 없음을 확인
- 자동 다운로드 없이 작은 안내부터 시작, 닫기/다시 열기/프로필 변경
- 전체 개수 도달, 로딩 정체, 전체 개수 미확인, 로그인 차단 및 취소
- 입력/CDN 검증, 큰 해상도 후보, 혼합 캐러셀, 영상 누락
- 발신자·탭·문서·작업 소유권 검증
- 실제 파일 complete 상태 후에만 완료 기록
- 워커 인스턴스 재생성 후 세션 상태 복원
- 페이지 이동 후 취소, 완료 이벤트 경합에 의한 중복 저장 방지

## 실제 Instagram 확인

앱 내 브라우저의 `@meta` 로그인된 프로필에서 main 안에 사진/동영상 미디어를 포함하는 게시물 링크가 존재하는 것을 확인했습니다. 공동 게시물은 다른 작성자의 경로로 연결될 수 있음을 확인해 지원했습니다. 프로필 상단의 가시 영역에는 첫 행 3개 게시물이 있고 다음 행은 화면 밖에 있었습니다.

이 DOM 확인은 **설치된 확장의 API 조회 및 실제 파일 다운로드 성공을 증명하지 않습니다.** 브라우저 도구의 확장 관리 페이지 접근이 차단되어, 사용자 로컬 설치 후 실파일 검증은 여전히 남아 있습니다.

## 예시 프로필 UI 검증

실제 배포 content.js를 로컬 예시 프로필에 로드하여 접힌 안내, 펼치기, 현재 화면 버튼, 진행/완료, 닫기 및 전체 옵션을 검증했습니다. 최종 빌드에서 화면 3개 게시물 선택, 전체 옵션 실행 후 스크롤 위치 825 및 페이지 끝 도달, 예시 9개 저장 완료 표시를 확인했습니다. 닫기 후 호스트 요소의 실제 가시성은 false였습니다. 예시 API/다운로드 대역은 tests/fixtures에만 있고 배포 ZIP에는 없습니다. 테스트 프로필 화면은 사용자용 서비스가 아닙니다.

## 배포

0.1.0의 별도 작업 화면은 이전 설계입니다. 최신 0.2.0 설치 ZIP을 사용해야 합니다. 웹스토어 게시자 필수 정보/인증 및 실제 심사 접수는 아직 완료되지 않았습니다.
