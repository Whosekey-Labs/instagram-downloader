# 검증 기록

2026-09-22 / 버전 0.1.0

## 자동 검사

Node.js 내장 테스트 16개 통과: 입력 및 URL 검증, 후보 해상도 선택, 혼합 캐러셀, 영상 누락 처리, 응답 형식 및 페이지 커서 검증, 인증/429 실패, 콘텐츠 스크립트 발신자 검증, 순차 다운로드 완료·취소·중복·기록 실패 처리.

빌드 검사: Manifest V3, 권한 최소화, 모든 파일 참조, JavaScript 구문, 원격 실행 코드 없음. ZIP 무결성 및 SHA-256 생성.

## 브라우저 화면 테스트

로컬 개발 서버에서 출시 UI에 개발용 Chrome API 대역과 예시 응답을 연결해 확인했습니다. 실제 Instagram 조회/저장을 한 것으로 간주하지 않습니다.

- 계정 입력 후 미디어 목록 렌더링
- 동영상 필터에서 동영상만 표시
- 필터된 목록 전체 선택 시 정확한 선택 수 표시
- 선택 다운로드 종료 상태 표시
- 같은 파일을 다시 처리할 때 중복 건너뛰기
- 다음 페이지 추가 및 마지막 페이지 도달 시 추가 수집 버튼 비활성화
- 390px 폭에서 입력·선택·다운로드 바의 가로 넘침 없음
- 개발 화면 콘솔 오류 없음

## 실서비스 및 제출

- 앱 내 브라우저에서 `@meta` 프로필과 게시물 링크가 로그아웃 상태로 표시됨.
- 확장 설치 후 실서비스 API 조회와 실제 파일 열기: 사용자 로컬 설치 확인 대기.
- Chrome 개발자 대시보드: 로그인 후 게시자 계정 확인. 판매자/비판매자 선언, 공개 연락처 이메일 및 조직 인증 추가 조치에서 차단. 등록비 납부 내역은 미확인.
- Chrome 웹스토어 ZIP 업로드, 심사 접수 및 승인: 미완료.

실파일 검증이 끝나기 전 공개 릴리스는 테스트용 prerelease로 표기합니다.
