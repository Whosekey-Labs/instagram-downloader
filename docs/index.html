계정 프로필에 나타나는 작은 미디어 저장 안내. 기본 버튼은 현재 화면만 저장하고, 전체 옵션은 스크롤로 게시물을 모은 뒤 다운로드합니다.

0.2.0 설치 ZIP · 소스와 설치 방법

사용 방법

  1. 확장을 설치하고 Instagram 페이지를 새로고침합니다.
  2. 원하는 계정의 게시물 탭으로 이동합니다.
  3. 오른쪽 아래 '미디어 저장'을 펼쳐 현재 화면 다운로드를 누릅니다.
  4. 전체가 필요하면 전체 다운로드 옵션을 사용합니다.

별도 작업 웹사이트나 로컬 서버가 필요하지 않습니다. 실제 Instagram 파일 저장 검증 및 웹스토어 심사 전의 초기 테스트 버전입니다.

지원 범위

프로필 게시물 그리드의 사진·영상·릴스·캐러셀. 현재 세션에서 접근 가능한 콘텐츠만 처리합니다. Instagram 변경이나 제한으로 작동하지 않을 수 있습니다. 본인 콘텐츠 또는 저장 허락을 받은 콘텐츠에 사용하세요.
