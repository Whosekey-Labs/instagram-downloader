좋아하는 순간을,
내 폴더에.

Instagram 계정의 사진·동영상·릴스를 선택하고 내 컴퓨터에 저장하는 브라우저 확장입니다.

0.1.0 초기 테스트 버전 · 실제 Instagram 파일 저장 및 웹스토어 심사 전입니다.

테스트 버전 다운로드 ↗소스 코드

로컬에서 시작하기

  1. Releases에서 ZIP을 내려받고 압축을 풉니다.
  2. Chrome에서 chrome://extensions를 열고 개발자 모드를 켭니다.
  3. '압축해제된 확장 프로그램 로드'로 manifest.json이 있는 폴더를 선택합니다.
  4. 확장 아이콘을 눌러 계정명 또는 프로필 주소를 입력합니다.

내 브라우저에서 처리합니다

개발자 수집 서버, 광고, 결제, 추적 도구가 없습니다. Instagram이 로그인을 요구하면 Instagram에서 직접 로그인합니다. 사진/동영상 필터, 캐러셀 파일별 저장, 추가 페이지 조회, 중복 건너뛰기 및 취소를 제공합니다.

Instagram 웹 응답 변경 또는 접근 제한으로 작동하지 않을 수 있습니다. 비공개 콘텐츠 접근 권한을 우회하지 않습니다. 본인 콘텐츠 또는 저장 허락을 받은 콘텐츠에 사용해 주세요. Stories/Highlights는 아직 지원하지 않습니다.
