# 스토어 제출 및 로컬 테스트

## 준비한 파일

- `release/open-media-downloader-0.1.0.zip`: manifest.json이 ZIP 최상위에 있는 확장 패키지
- `release/open-media-downloader-0.1.0.zip.sha256`: 무결성 확인 값
- `store/assets/icon128.png`: 128×128 아이콘
- `store/assets/promo440.png`: 440×280 홍보 이미지
- `store/assets/screenshot-start-demo.png`, `screenshot-collection-demo.png`: 1280×800 UI 스크린샷. 예시 데이터를 표시한 개발 화면이며 실제 Instagram 다운로드 증거가 아님. 최종 심사 제출 시 로컬 확장 실사용 화면으로 교체 권장.
- `store/listing.md`: 설명, 단일 목적, 권한 사유, 개인정보 선언 참고, 심사자 테스트 지침
- `PRIVACY.md` 및 `src/privacy.html`: 개인정보처리방침

## 현재 차단 단계

개발자 대시보드 로그인 후 게시자 계정은 확인했습니다. 항목 화면 진입 시 **판매자/비판매자 선언**이 필요하며, 설정에는 **공개 연락처 이메일 미등록 및 계정 인증 추가 조치**가 표시됩니다. 조직 인증 화면은 조직 등록 서류와 현재 주소 증빙을 요구합니다. 사용자 사실 확인/서류 제출을 대신 처리하지 않았습니다. 아직 확장 업로드 화면까지 진입하지 못했으며 **심사 제출 완료가 아닙니다.** 등록비 납부 내역은 확인하지 않았습니다.

브라우저 자동화 도구는 확장 관리 내부 페이지 접근을 차단합니다. 로컬 '압축해제된 확장 로드'는 사용자가 직접 수행해야 합니다. 기존 Chrome 확장을 앱 내 브라우저에서 다운로드한 것과, 개발 중인 로컬 확장을 해당 브라우저에 로드할 수 있는지는 별개로 확인해야 합니다.

## 남은 순서

1. 로컬 확장 설치 후 `meta` 등 허용된 계정의 사진·영상 파일 저장 확인.
2. https://chrome.google.com/webstore/devconsole 에서 판매자/비판매자 선언, 연락처 이메일 및 조직 인증을 사용자 직접 완료.
3. 게시자 계정/연락처 확인 후 새 항목에 ZIP 업로드.
4. `listing.md` 내용 입력, 개인정보 URL 설정, 실제 UI 이미지 업로드.
5. 계정 정보가 필요한 상인/비상인 선언과 인증은 사용자가 사실에 맞게 입력. 예시나 추정 값을 입력하지 않음.
6. 테스트 지침 및 배포 국가/공개 범위를 확인하고 Submit for review. 사용자 요청은 심사 제출까지 포함하므로, 필수 사용자 단계가 완료되면 중복 승인 요청 없이 제출을 진행할 수 있음.
7. 접수된 항목 ID, 버전, 검토 상태를 확인해 기록. 자동 게시 대신 승인 후 수동 게시 옵션을 사용할 수 있음.

승인 전 GitHub의 ZIP으로 로컬 테스트는 가능합니다. 자동 테스트 통과는 실제 Instagram 접근 성공이나 스토어 승인을 뜻하지 않습니다.
