# 웹스토어 입력 문안

## 이름
Open Media Downloader

## 짧은 설명
Instagram 계정의 사진·동영상·릴스를 선택하고 내 컴퓨터에 저장하는 무료 오픈소스 도구입니다.

## 상세 설명
Instagram의 사진과 동영상을 내 폴더에 모아보세요.

Open Media Downloader는 계정명 또는 프로필 주소로 미디어 목록을 확인하고 필요한 파일을 선택하여 저장하는 무료 오픈소스 확장입니다.

• 계정명 / 프로필 URL 입력
• 사진, 동영상, 릴스, 여러 파일이 포함된 게시물 지원
• 사진 / 동영상 필터와 선택 다운로드
• 추가 페이지 가져오기와 지정한 게시물 수까지 수집
• 계정별 폴더 및 게시물별 파일명
• 로컬 저장 기록으로 중복 다운로드 건너뛰기
• 진행 상황 표시 및 중단

별도 회원가입, 개발자 서버, 광고 또는 결제가 없습니다. Instagram이 로그인을 요구하면 Instagram 웹사이트에서 직접 로그인합니다. 확장은 비밀번호나 쿠키 값을 읽거나 보관하지 않습니다.

Instagram이 현재 세션에 제공하는 미디어만 접근합니다. 계정 전체 조회를 보장하거나 접근 제한을 우회하지 않습니다. Instagram 웹 응답 변경으로 기능이 중단될 수 있습니다. Stories와 Highlights는 이 버전에서 지원하지 않습니다.

본인이 소유하거나 저장 허락을 받은 콘텐츠에 사용해 주세요. Instagram / Meta와 무관한 독립 프로젝트입니다.

소스 코드 및 문의: https://github.com/Whosekey-Labs/instagram-downloader

## 단일 목적
사용자가 지정한 Instagram 계정의 접근 가능한 사진·동영상을 목록으로 확인하고 선택하여 사용자의 컴퓨터에 저장합니다.

## 권한 사용 사유
- downloads: 사용자가 선택한 미디어를 계정별 다운로드 폴더에 저장하고 해당 작업의 완료, 실패, 취소 상태를 확인합니다.
- storage: 이미 저장한 파일의 식별자와 저장 시각을 로컬에 보관하여 같은 파일의 중복 저장을 방지합니다. 설정 화면에서 삭제할 수 있습니다.
- www.instagram.com 호스트: 사용자가 입력한 계정의 Instagram 탭에서 프로필과 미디어 목록을 조회합니다. 다른 사이트에 대한 접근은 요청하지 않습니다.
- 원격 코드: 사용하지 않습니다. 실행 코드는 모두 ZIP에 포함되어 있습니다.

## 개인정보 항목 검토
개발자 서버로 수집하는 데이터는 없습니다. 다만 확장은 기능 수행을 위해 계정 식별자, 프로필 및 게시물 콘텐츠, 미디어 URL, 사용자가 선택한 다운로드를 처리합니다. 해당 대시보드의 데이터 분류 정의에 따라 **개인 식별 정보(계정명/공개 프로필), 웹사이트 콘텐츠(게시물·이미지·영상), 사용자 활동(선택/다운로드 기록)** 항목을 보수적으로 검토하고, 실제 정의와 일치하는 항목을 선언합니다. 비밀번호·인증 코드·쿠키 값·금융/건강 정보 수집은 없습니다. 사용하지 않는 수집 항목을 임의로 체크하거나 전체를 '데이터 없음'이라고 단정하지 않습니다.

개인정보처리방침 URL: https://whosekey-labs.github.io/instagram-downloader/privacy.html

## 심사자 테스트 지침
1. 확장을 설치하고 아이콘을 눌러 작업 탭을 엽니다.
2. 접근 권한이 있는 테스트 계정명 또는 프로필 주소를 입력합니다.
3. 로그인 요청이 나오면 'Instagram 열기'를 눌러 심사자가 관리하는 계정으로 Instagram에 직접 로그인하고, 다시 프로필을 조회합니다. 확장에 로그인 정보를 제공하지 않습니다.
4. 처음 가져온 게시물 중 사진 1개와 동영상 1개를 선택하고 다운로드합니다.
5. 다운로드 폴더의 OpenMedia/계정명 폴더에서 실제 파일이 열리는지 확인합니다.
6. 같은 선택으로 다시 다운로드하면 완료 기록이 있는 항목을 건너뜁니다.
7. '더 가져오기', 사진/동영상 필터, '작업 중단', 저장 기록 삭제를 확인합니다.
8. 요청 제한 또는 추가 인증 시 자동 재시도가 없고 안내가 표시되는지 확인합니다.

테스트 자격 증명은 소스/ZIP/공개 문서에 포함하지 않습니다. 대시보드가 전용 테스트 계정을 요구하면 게시자가 비공개 테스트 지침에서 직접 제공합니다.
