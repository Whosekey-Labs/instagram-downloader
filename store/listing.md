# 웹스토어 문안 · 0.3.0

## 이름
Open Media Downloader

## 짧은 설명
Instagram 프로필에서 현재 화면의 미디어를 저장하거나, 전체를 스크롤해 모은 뒤 다운로드하는 무료 오픈소스 도구입니다.

## 상세 설명
Instagram에서 원하는 계정으로 이동한 다음, 오른쪽 위의 작은 '미디어 저장' 안내를 눌러 주세요.

• 현재 화면 다운로드: 클릭 시점에 화면에 보이는 게시물만 저장합니다. 자동 스크롤하지 않습니다.
• 개수 지정: 프로필 앞쪽의 N개 게시물을 저장하며, 묶음 파일은 모두 저장합니다.
• 기본값 저장: 계정 간에 다운로드 개수를 유지합니다. 이번만 숫자를 바꿔 저장해도 기본값은 유지됩니다.
• 전체 다운로드 옵션: 페이지를 스크롤하며 게시물을 모은 뒤, 전체 수집이 확인되면 순서대로 저장합니다.
• 전체 개수가 확인되지 않거나 로딩이 멈추면 모인 게시물만 저장할 수 있습니다.
• 사진, 동영상, 프로필에 표시된 릴스와 여러 장의 게시물을 지원합니다.
• 저장 진행, 중단, 중복 건너뛰기, 계정별 폴더를 제공합니다.
• 안내는 접거나 닫을 수 있고 확장 아이콘으로 다시 열 수 있습니다.

별도 작업 웹사이트, 회원가입, 개발자 서버, 광고, 결제가 없습니다. 로그인은 Instagram에서 직접 진행합니다. 확장은 비밀번호·인증 코드·쿠키 값을 읽거나 보관하지 않습니다.

계정의 게시물 탭에 표시된 콘텐츠를 대상으로 합니다. 프로필에 공유되지 않은 릴스, Stories, Highlights, Tagged, Reposts는 지원하지 않습니다. 비공식 웹 응답을 사용하므로 Instagram 변경으로 작동하지 않을 수 있습니다. 비공개 계정 권한이나 접근 제한을 우회하지 않으며 전체 수집을 보장하지 않습니다.

본인 콘텐츠 또는 저장 허락을 받은 콘텐츠에 사용하세요. Instagram / Meta와 무관한 독립 프로젝트입니다.

소스와 문의: https://github.com/Whosekey-Labs/instagram-downloader

## 단일 목적
Instagram 프로필에서 사용자가 선택한 범위의 접근 가능한 미디어를 사용자의 컴퓨터에 저장합니다.

## 권한 사유
- downloads: 선택한 파일을 저장하고 이 확장이 시작한 다운로드의 상태를 확인하거나 취소합니다.
- storage: 중복 방지를 위한 로컬 완료 기록 및 워커 재시작을 위한 임시 작업 상태 및 사용자가 저장한 다운로드 기본 개수를 보관합니다.
- www.instagram.com: 프로필 페이지에 작은 안내 표시, 화면의 게시물 링크 수집, 사용자 요청에 따른 미디어 조회.
- 원격 코드: 사용하지 않습니다. 모든 실행 코드가 ZIP에 포함됩니다.

## 개인정보 선언 참고
계정명/공개 프로필 식별자, 게시물 링크·이미지·영상, 사용자 선택에 따른 다운로드 기록을 로컬에서 처리합니다. 개발자 서버로 수집하지 않지만 대시보드의 실제 데이터 분류 정의에 따라 개인 식별 정보, 웹사이트 콘텐츠, 사용자 활동 항목을 보수적으로 검토해야 합니다. 전체를 '데이터 없음'으로 단정하지 않습니다. 비밀번호·인증 코드·쿠키 값·금융/건강 정보는 수집하지 않습니다.

개인정보처리방침: https://whosekey-labs.github.io/instagram-downloader/privacy.html

## 심사 테스트 지침
1. 확장을 설치하고 Instagram을 새로고침합니다. Instagram 로그인이 필요하면 심사자가 관리하는 계정으로 직접 로그인합니다.
2. 접근 권한이 있는 계정의 게시물 탭으로 이동합니다.
3. 오른쪽 위 작은 안내를 펼쳐 '현재 화면 다운로드'를 누릅니다. 페이지가 스크롤되지 않고 현재 보이는 게시물만 저장되는지 확인합니다.
4. 다운로드 폴더 OpenMedia/계정명에서 사진과 영상을 직접 엽니다.
5. 같은 범위를 다시 저장하면 로컬 완료 기록으로 중복을 건너뜁니다.
6. 전체 다운로드 옵션을 열고 전체 수집을 실행합니다. 자동 스크롤 → 수집 완료 확인 → 다운로드 순서인지 확인합니다. 일부만 모인 경우 전체 완료로 표시하지 않아야 합니다.
7. 개수를 입력해 기본값으로 저장한 뒤 다른 계정으로 이동해 값이 유지되는지 확인합니다. 숫자를 임시로 수정해 실행해도 저장된 기본값이 바뀌지 않아야 합니다.
8. 중단, 안내 접기/닫기, 확장 아이콘으로 다시 열기, 다른 계정으로 이동, 저장 기록 삭제를 확인합니다.

공개 문서나 ZIP에 테스트 로그인 정보는 포함하지 않습니다. 전용 테스트 계정이 필수라면 게시자가 비공개 지침에 직접 제공합니다.
